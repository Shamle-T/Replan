# Replan Demo Script

1. Open Plan and inspect the deliberately imperfect demo schedule.
2. Add a flexible task with a priority and deadline, then use **Find a time**.
3. Add a fixed commitment and observe that it remains anchored after **Optimize day**.
4. Configure travel or an outdoor location to demonstrate additional constraints.
5. Switch to Live Day, start the simulation, and jump to the next event.
6. Mark the current event done early or request more time.
7. Review the replan proposal, change the break duration, and apply it.

The result is deterministic: the same tasks, constraints, and current time produce the same schedule.
